01 / Try it in minutes

从完整题目，到可审核的反馈。

  1. 01
    提供本次作业要求

    粘贴 Markdown 或选择 .md 文件；其中的明确评分表可以直接作为 rubric。

  2. 02
    生成批改草稿

    读取 Canvas 提交或本地代码，查看逐项分数、代码证据与模型/工具轨迹。

  3. 03
    审核后再回写

    修改评语和分数，逐份确认，再明确提交到 Canvas。

# Python 3.10+ · macOS / Linux / WSL
git clone https://github.com/chaoyuhao/mini-homework-agent.git
cd mini-homework-agent
python3 -m venv .venv
source .venv/bin/activate
pip install -e '.[pdf]'

# No credentials or network calls
mini-homework-agent demo --offline
mini-homework-agent serve
# Open http://127.0.0.1:8765

03 / Questions

使用前先了解这些

没有 API key 也能体验吗？

可以。离线演示使用两份固定的合成示例，不连接模型或真实课程，也不能回写成绩。它展示审核流程，不代表 AI 准确率。

我的其他 Agent 能调用它吗？

可以。CLI 接收课程、作业 ID 和 Markdown 要求文件。Agent 集成指南说明如何生成草稿以及保留人工审核边界。

会运行学生程序或自动查重吗？

不会。当前支持文件读取与 AST 语法检查，不运行代码或查重；可选本机 OCR 读取截图和文档图片。静态评分建议仍需你审核。

作业数据会发到哪里？

要求与提交正文会发送到你配置的模型服务。程序不主动发送凭证和学生元数据，但正文里的个人信息仍可能包含在内。草稿和轨迹保存在本机。
