01 / Try it in minutes

From the question to reviewed feedback.

  1. 01
    Bring the requirements

    Paste Markdown or choose a .md file. Explicit scoring tables become the rubric.

  2. 02
    Generate drafts

    Read Canvas submissions or a local Python file. Inspect scores, code evidence, and the model/tool trail.

  3. 03
    Review and publish

    Edit feedback and scores, approve individual drafts, then explicitly write them back to Canvas.

cd mini-homework-agent
python3 -m venv .venv

03 / Questions

Before you start

Can I try it without API keys?

Yes. The offline demo uses two fixed, synthetic examples and cannot publish to a real course. It demonstrates the review workflow, not model accuracy.

Can my own AI agent use it?

Yes. The CLI accepts course and assignment IDs plus a Markdown requirements file. The agent-integration guide explains draft creation and the separate human-approval boundary.

Does it execute student code?

No. The current version reads supported files and can inspect Python AST syntax. It does not run tests or detect plagiarism. Optional local OCR reads screenshots and document images. Static suggestions still require review.

What happens to course data?

Your configured model service receives requirements and submission text. Credentials and student metadata are omitted; personal information inside the submitted text may still be sent. Drafts and trajectories stay local.
