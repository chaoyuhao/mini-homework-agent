# Two independent Python questions

## Question 1: Eligibility

Implement `eligible(age)`. Return `True` for age >= 18 and `False` otherwise.
Do not require extra input validation beyond numeric ages.

## Question 2: Integration

Write a program that calculates the definite integral of f(x)=x*x over [0, 1].
Use a mathematically valid analytic or numerical method. A reasonable numerical
approximation of 1/3 is acceptable. Additional benchmarks or a testing framework
are not required.

# Scoring

Scoring mode: holistic

Check both questions independently, with evidence from each implementation.
Both must meet their stated requirements for full credit. This assignment has
no point allocations per question; do not invent equal weights.
Provide shared leniency, late, and comment rules separately with `--policy`.
